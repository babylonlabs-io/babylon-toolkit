Delegated claim — depositor as claimer

The vault provider is offline. This page runs the whole claim from the browser with the SDK's services/delegated-claim surface. Signet only. Every export it calls is experimental — see the README beside this file.

Every field below is read from the vault's on-chain registration, not from the vault provider. They are what bind the provider-served graph to this vault. Every field is required.
